## Epistemic Standard

Claims should distinguish:

**DEFINED → IMPLEMENTED → COMPUTED → VERIFIED → ATTESTED → HISTORICAL → HYPOTHESIS → METAPHOR → UNSUPPORTED → DEPRECATED**

A deployment configuration is not proof of deployment. A visualization is not proof of the modeled phenomenon. A historical benchmark is not current validation without a reproducible run.
